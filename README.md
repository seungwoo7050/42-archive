# push_swap

제한된 스택 연산만으로 정수 입력을 정렬하고, 생성한 명령의 정확성과 비용을
검증하는 C 프로젝트다.

## 초기 개발 규약

- 스택 상태와 공개 연산 계약은 하나의 헤더에서 관리한다.
- 값과 정렬 순위는 모든 연산에서 함께 보존한다.
- 표준 출력에는 정렬 명령만 기록하고 오류는 표준 오류로 분리한다.
- 각 기능은 빌드 가능한 책임 단위로 추가하고 경계 조건을 검증한다.
- 빌드 산출물과 로컬 테스트 캐시는 버전 관리에 포함하지 않는다.

현재 저장소는 개발 원칙만 정한 초기 상태다. 구체적인 실행 방법과 정렬
전략은 구현이 갖춰지는 과정에서 갱신한다.
