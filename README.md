# libft

표준 C 라이브러리의 핵심 동작을 직접 구현하며 바이트, 문자열, 메모리,
소유권 경계를 학습하기 위한 정적 라이브러리 프로젝트다.

## 초기 개발 규약

- 공개 함수와 자료형은 `libft.h`에서 관리한다.
- 구현은 책임별 디렉터리와 작은 컴파일 단위로 나눈다.
- C99와 엄격한 경고 옵션을 기준으로 빌드한다.
- 기능을 추가할 때 정상 경계와 실패 경로를 함께 검증한다.
- 빌드 산출물과 로컬 실행 파일은 버전 관리에 포함하지 않는다.

현재 저장소는 개발 규약만 정한 초기 상태다. 구체적인 API와 사용법은
구현이 갖춰지는 과정에서 갱신한다.
